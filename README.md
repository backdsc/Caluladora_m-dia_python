# Caluladora_m-dia_python
🧮 Calculadora de Média Escolar – Projeto Inicial

Esse projeto é uma calculadora simples de média de notas, feita em Python. A ideia inicial foi não deixar meu GitHub parado enquanto estudo e pratico.

Mas calma que isso é só o começo! 🚀
Em breve, pretendo transformar esse código básico em um sistema mais robusto de cálculo de médias — seja pra cursos, escolas ou faculdades — com melhorias como:

Interface usando HTML, CSS e JavaScript

Backend em Python (talvez com Flask ou FastAPI)

Quem sabe até um projetinho fullstack, feito por puro hobby e vontade de aprender 💻❤️
